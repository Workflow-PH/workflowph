Local SVG icons go here and are referenced as `<Icon name="filename" />`.

Iconify icons (`<Icon name="lucide:arrow-right" />`) resolve from
`@iconify-json/lucide` and do not need a file here.

This is where the official WorkFlow PH brand marks land once they exist as SVG
(WF-A4) — drop `logo.svg` and `wordmark.svg` in, then replace
`src/components/layout/Wordmark.astro`.
