Archive-tier events never render a detail page, so this body is ignored. They
appear as a single row in the list at the bottom of `/showcase`.

Use this tier for every event that doesn't have a complete Asset Kit. It is how
the full history gets published — which is what makes the org look established —
without needing twenty sets of photos. Copy this file, change the frontmatter,
delete the body.
